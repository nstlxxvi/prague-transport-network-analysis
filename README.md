# prague-transport-network-analysis
Analysis and visualization of Prague public transport network using Python, NetworkX and Folium.

# description
This project focuses on the analysis and visualization of Prague public transport data. After cleaning and processing the dataset, a transport network was created and analyzed using graph theory methods. The resulting data can be used to identify important transport hubs, discover patterns in the network, and answer various questions about the structure and connectivity of Prague's public transport system.
